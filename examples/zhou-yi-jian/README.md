# 《周一见》：从素材到连贯的短篇

本案例展示 writer-pen 2.4.0 下的一次实质改稿。它经过多轮读者反馈，不是单条提示词的一次生成。按虚构作品展示，不指认现实人物或企业。

## 为什么这样改

| 原先的问题 | 实际处理 | 希望改善的阅读体验 |
|---|---|---|
| 直接采用“一度以为要结婚”的素材概括，人物发展不足 | 改为等下班、问转正、拍租房广告、暂缓买票的逐级投入 | 读者能经历期待如何变实，不只被告知他很认真 |
| 从吃饭直接跳到宿舍楼下 | 写出晚饭结束、她打算走回去、他提出送行 | 不用在关键亲近处倒回去猜人物怎么到场 |
| 先一个人吃烧烤，才想到约她 | 先邀约，等到七点未获回复，饿了才独自用餐 | 行动来自当时处境，而不是为反转摆放人物 |
| 一次交流被拆成数个短段 | 把等候、她的消息与他的回复放在同段；去留问答适度转述 | 普通反应不再次次获得重音，交流能连续读完 |
| 已写看见牵手，又单独写先看手再抬头 | 压缩重复发现过程，尽早进入桌边问答 | 保留必要惊讶，把更多注意留给人物如何应答 |
| 结尾容易补抽象感悟或物件寓意 | 保留刚上菜、托词和烫嘴的现场联系，以双方的“周一见”收束 | 情绪来自经历，不由作者事后总结替读者感受 |

这些是本篇的编辑选择，不是所有小说都必须少分段、删物件、用动作代替心理，或以留白结尾。

## 一个实际比较

本轮独立读者提出：要不要增加她对两人关系的可观察表达，让读者有更多判断依据？实际试写过在亲吻后加入：

> 我问：“那咱俩算在一起了？”她说：“先这样处着呗。”

这能让关系含混被明确说出，但也改变了故事：他变成听见含混答复仍继续作打算的人；她的台词会提前提示读者防备。当前稿选择不加，让此前相处与期待保持分量，同时不替她作关系定性。读者仍可能追问她的责任，这个分歧没有被强行消除。
