# 《经还在西边》

以取经团队需要裁掉一人为设定，唐僧、孙悟空、猪八戒、沙僧与白龙马分别陈述自己对取经的价值。本文属于文学创作，非真实事件。

本例展示初始立意提示词与经多轮修改后的作品，不代表单条提示词的一次生成。

### 经还在西边

取经未成，队里要减一人。

#### 唐僧

揭一纸佛帖，收一声师父，<br>
贫僧把五行山下的猴王，<br>
带上西行路。

女王拿一国江山，<br>
换贫僧留下成亲。<br>
徒弟去灵山，贫僧做国君。<br>
喜筵上催她盖的，<br>
仍是西行的印。

长安法坛，菩萨说真经能度苦，<br>
贫僧下坛，请命西行。<br>
那时还不识悟空，<br>
不识八戒、悟净，<br>
十万八千里，已在佛前应承。

一炷香，一身凡骨，<br>
此去吉凶，便都押在这条路。<br>
经不回东土，<br>
贫僧不回长安。

#### 孙悟空

砍头，剖腹，滚油锅，<br>
车迟国三场，老孙全接过。

狮驼国，群妖架火，<br>
老孙搬龙王，先护锅底，<br>
保住这一笼和尚。<br>
大鹏的外甥坐灵山，<br>
俺去请他挪莲台，亲自来收场。

白虎岭，三棒打出白骨，<br>
一纸贬书，赶老孙回山。

八戒搬来黄袍怪的骂，<br>
老孙抄棒，直奔宝象。<br>
妖怪的账，等着算，<br>
先找那不认俺的和尚。

黄袍怪把师父变作虎，<br>
老孙一声咒，一口水，<br>
虎笼里，喷回个唐三藏。<br>
他连声道谢，老孙把棒一扛：<br>
“留着，到灵山再谢。”

#### 猪八戒

八百里荆棘，缝住西行道，<br>
老猪长身，长钯，<br>
一日一夜，刺往两边倒。

花果山，头磕了，大哥不动。<br>
俺替黄袍怪添两句骂，<br>
往他耳边一送。<br>
束虎裙，抄铁棒，纵身下山；<br>
来时俺求他，去时他催俺。

真假猴王，闹上天庭，闹下阴曹，<br>
水帘后那两包行李，<br>
还得有人去挑。<br>
俺认不准猴哥，却认得洞门。<br>
进洞抡钯，出洞背囊，<br>
关文、袈裟，这一伙人的家当，<br>
老猪给扛回来了。

#### 沙僧

八百里流沙，鹅毛沉底。<br>
颈上九颗骷髅，<br>
解下来结作法船。<br>
俺这双夺过人命的手，<br>
这回，托着师父过河。

真假猴王那一场，<br>
师父挨了棒，关文遭了抢，<br>
这笔账，全记在大哥头上。

俺闯水帘，奔南海，扯他回山，<br>
让那张借来的脸，<br>
当面见一见正主。

狮驼国，满城传师父已入妖腹。<br>
大哥引路，俺砸铁锁。<br>
柜门开了，师父还在发抖。

俺把他的胳膊，搭上俺的肩，<br>
从一城死讯里，<br>
扶出个活生生的师父。

#### 白龙马

鹰愁涧，龙身换作马身，<br>
西海的浪，换了一路风尘。<br>
驮的是师父，挣的是金身。

朱紫国，国王卧病，师父作保。<br>
三位师兄捧着盏，围到我马槽。<br>
几滴龙尿，和进乌金丹，<br>
三年沉疴，一朝散；<br>
国王下病榻，师父上马鞍。

宝象国，师父困虎笼，<br>
师兄无音信，我先挣断缰。<br>
变宫娥，舞宝刀，直取黄袍。<br>
负伤回槽。

二师兄要散伙，我咬住他的袍：<br>
“大哥还请得回，<br>
师父还救得了。”
