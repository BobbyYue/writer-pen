# 邓煜：以数学为生

## 他决定读数学

2009年春天，邓煜回深圳看望围棋启蒙老师陈雅华。他在北大念了两年数学，就要去美国接着读本科。陈雅华在当时的博客里记下了这次见面。她的丈夫余昌民提到，靠做数学过日子，往后也许清贫，也许寂寞。邓煜笑了笑，说：“我不在乎有多少钱。”陈老师伸出手，摸了摸他的脸。

陈老师还记得，邓煜读小学二年级时，想在教师节亲手送她一张贺卡，让母亲陪着在校门口等。迟迟没等到老师，他急得哭了。后来邓煜的棋下得越来越好，陈雅华便请职业六段梁鹤年指点他。

十二岁那年，邓煜去参加全国围棋定段赛。到了最后三盘，赢一盘就能成为职业棋手。他三盘都输了。多年以后有人问起，他还记得头一盘输给了丁烈。后两盘他那时觉得可惜，再回想，自己究竟占没占过上风，他也说不准了。棋谱没有留下。

下棋以外，他最喜欢的是做数学题。在深圳高级中学，冯跃峰老师教他奥数。冯老师记得，邓煜遇上难题，会翻书找类似的题，也会拿来和他一起琢磨；实在做不动，就搁几天再试。2006年去福州参加全国数学冬令营，他是全场唯一的满分，还因为一道题用了跟命题组不同的解法，另得一个特别奖。

那年高二，他又拿了国际奥数金牌。学校希望他高三再比一年，邓煜谢绝了。他觉得自己比过了，想用这一年读点大学里的数学。父母建议报北大的元培计划，到大二再决定学什么。邓煜说想直接念数学，家里依了他。

## 从做题到选题

在北大读大一，邓煜翻周民强的《实变函数论》，遇到喜欢的习题，就拿给同学看。大二跟刘和平做研究，刘老师给他一本傅里叶分析专著，让他从最后一章读起，遇上不懂的再往前翻。一个月后，那一章读完了，刘老师给他出了一道题。邓煜做出了证明。文章还没改完，他就转学去了麻省理工。

在麻省理工，有一回他听娜莫德讲波。描述波怎样变化，数学家手里有方程；娜莫德却把开头的波形交给概率去选。这样选出来的波，哪怕形状乱得很，方程还能告诉人往后它会是什么模样吗？邓煜读过概率论，有些定义一直不知道能用来做什么。这个问法吸引了他。报告一散，他就去找本校的斯塔菲拉尼教授，请她给自己出一道跟它有关的题，留到暑假里做。

秋天返校，他带回了一篇论文。文章后来发表了。听说同岁的约翰·帕登本科就在《数学年刊》发了论文，邓煜也有点羡慕。

2011年到普林斯顿读博，他选了约内斯库做导师。这位老师既研究波，也做流体和相对论，邓煜还想多接触几种问题。他自己惦记的，仍是娜莫德讲过的那一类。碰上起伏特别剧烈、甚至有间断的波形，他用当时的办法能证明一些情形，离他想弄清的事还差得远。

读博后期，他接着约内斯库和同事的工作，研究另一道题：一个原本平稳的系统，起初只受了一点扰动，时间一长，还能不能保持稳定？快毕业时，他在学校的采访里说起自己的打算：想拿这几年用过的办法，试一试起初扰动就很大的情形。

2015年交出的博士论文里，两方面的工作都有。对于随机选取的波形，他写下了自己在一种特定方程上证明的结果。还有些情形，用过的办法都不够，他只好先放一放。后来回想起来，邓煜说，换过几道题，总没有当初那一个那么吸引他。

## 在纽约找教职

在普林斯顿读完博士，邓煜去了纽约大学做博士后。那几年，他和人合写过一篇研究流体的论文。他很喜欢他们想出来的办法，审稿人却指出，用这个办法能证明的结论相当有限。多年后说起这篇论文，他仍旧喜欢那个办法，也觉得审稿人说得有道理。

到了2017年前后，博士后聘期快满，他还没等到心仪大学的教职邀请，金融公司却来找他，薪水是留在学界的好几倍。邓煜告诉对方，眼下还想做数学；倘若以后也做不出自己想做的研究，他会考虑去公司。要不要去，他认真考虑了几个月。

那时他也想过，留在学界，往后的日子大概就是去学校，做数学，回家，第二天再去。他喜欢一连几个钟头只想一道题。按他后来的说法，那几年大多数时候他对自己的工作有信心，拿不准的是同行会怎么看。

在纽约大学任教的贾拉勒·沙塔记得，邓煜在系里常拿着本漫画。邓煜后来讲起自己读过的一本漫画：几个人相识，各有工作，各有难处，日子一点点过好了。读到这里，他想到自己，不知道往后的日子会过得怎么样。他一向喜欢独处，在纽约却头一次觉得孤单。

那年冬天，他搭火车去长岛南岸，在长滩住了两天。沿海岸走，写了一首《长滩听海》。据他回忆，去之前研究没有进展，回来也没有。约莫一个星期没工作，他自己又想做数学了。2018年，南加州大学给了他一个助理教授的职位，他接受了。

## 一起做数学

在洛杉矶，一次聚餐后，岳海天开车送邓煜回住处。岳海天刚来做博士后，还没碰上一道自己真想做的题。车上聊起博士论文，他研究的正是邓煜搁下好几年的那类问题：起初的波形哪怕很不规则，能不能用方程确定它往后怎样变化？邓煜想再试试。他提议把娜莫德也请来，当初就是她的报告把他引到这个问题上来的。

岳海天记得，三个人在黑板前讨论着，邓煜有时就不作声了。他和娜莫德接着算。过了五分钟，十分钟，有时足有一刻钟，邓煜忽然擦去他们写的算式，把另一种算法写给两人看。三人合写的那篇论文，后来登在了《数学年刊》上。

扎赫尔·哈尼来找邓煜时，已经问过好几位同行。他想弄清许多列波相遇时，能量怎样从一种频率传到另一种频率。他缺一个既懂方程、又能把概率用进来的人。哈尼记得，他只说了个大概，邓煜就知道该找哪篇文章，还把文章里的办法改了改，用到他手上这道题里。

两人把原先只能算很短一段时间的结果往前推了一截。到这里，邓煜想收手了：时间越长，波和波相互影响的次数越多，手里的办法未必够用。哈尼惦记的却是他们还没算到的那一段。物理学家想看的，是能量在不同频率的波之间怎样重新分布；照现在这样停笔，恰好还看不清。哈尼劝他再做下去。邓煜听了他的。两个人把原来的办法放到一边，另想了一套，终于算到了哈尼想看的时候。

马骁还在读博士时，问过邓煜一个问题：既然他们能算那么多列波彼此怎样影响，把波换成气体里一颗颗相撞的小球，能不能也这样算？据马骁回忆，邓煜说自己还没想过，也许可以。马骁回去就开始琢磨那些小球。后来邓煜邀他和哈尼一道做，三个人先花了三四个月，看看这个想法究竟行不行。

麻烦出在怎么算那些接连发生的碰撞。他们把哪些小球先后碰过面画成图，再把复杂的图拆开来算。马骁记得，邓煜起先设计了一种拆法，沿着那条路想了几个月，算法本身却有问题。邓煜后来说，少了马骁，他们会多走不少弯路。马骁说，凭邓煜的本事，再给他一年，也许他自己就能做出来；随即又笑着补了一句，少了那两位，说不定自己多花一年也行。

证明快收尾时，邓煜正在国内看望父母。饭桌上，母亲看出儿子又在想数学，就由他想一会儿。

巴黎的伊莎贝尔·加拉格尔研究气体已有多年。她和几位同行拿到三个人的论文，有些地方读不下去。邓煜飞到巴黎，花了一个星期，和他们一道把证明从头往下理。后来三位作者又动笔，把那些读者不容易跟上的推导写得更细了。

---

2026年7月，邓煜在费城领了菲尔兹奖。他已是芝加哥大学的教授。有人问这奖对他要紧吗，他说要紧。做了这些年的研究，得到同行的肯定，他很看重。往后选自己感兴趣的题，也更自由些。

获奖后的采访里，记者又问他，当年金融公司的薪水高出那么多，为什么没去？邓煜说，收入原本就没排在头一位，后来又有了南加州大学的教职，他愿意留下来做数学。但在纽约那阵子，如果他觉得自己往后做不出更好的研究，也可能就去做别的了。
