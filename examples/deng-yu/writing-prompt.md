# 《邓煜：以数学为生》是怎么写的

这份提示词根据多轮创作与改稿整理，供试写和改写同类人物稿使用。它不是最早的原话，也不是一次生成成稿的记录。

## 可复用提示词

```text
用 writer-pen 根据下面的公开采访，写一篇关于数学家邓煜的纪实人物特写。写给不熟悉数学研究的读者，以离线 HTML 交付，文末附采访与资料出处。

获奖后的履历看起来很顺。可一个从小喜欢数学的人，为什么也认真考虑过改行？把那次选择放回他的成长经历里。挑有出处的事展开：他怎样发现自己想做的问题，又怎样和意见不同的人一起工作？不必每个阶段都凑一件成就。研究过程讲到读者能理解他当时的处境就够了。

用细节写人，不神化他，也不替他补心理或对白。分清本人怎么说、旁人记得什么。材料只说明他考虑过一条路，就让那条路保留当时的可能，不拿后来的奖项倒推他早就知道答案。
```

**试写材料**：可把下面的链接连同提示词发给能读取网页的助手；不能读取时，附上你要使用的采访摘录。

- [邓煜自述：学习、选题和走弯路的经历](https://pku.org.cn/info/1013/48982.htm)
- [Quanta 访邓煜、亲友与合作者：转行的犹豫和后来的合作](https://www.quantamagazine.org/yu-deng-wins-the-fields-medal-2026-for-his-work-on-the-random-data-problem-20260723/)
- [马骁自述：他与邓煜、哈尼怎样开始合作](https://aga.ustc.edu.cn/info/1197/35771.htm)

换写其他人物时，把“为什么考虑改行”换成材料里真正值得追问的事，不必给每个人安排低谷。
