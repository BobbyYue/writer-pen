# 练习：一次解决一个具体写作问题

用户有作业时先读作业；没有作业时根据其想练的能力出题。
既无材料也无目标时，可从短场景或句子练习起步，不要求完成长问卷。

## 练习闭环

- 指出本次要练的判断，例如让同一段等待产生不同的节奏，而不是笼统地“提高文笔”。
- 给一个可执行任务，条件足够明确，允许多种成立的写法。
- 默认先让用户尝试。除非用户要求示范或对照，不提前给“标准答案”。
- 收到作品后，先指出一处实际有效的选择，再聚焦最值得修改的一处，引用稿件说明。
  没有必要优点时不虚夸；问题多时先处理影响最大的，不开一张全面缺陷清单。
- 用一个明确的改写动作推进下一次尝试；需要示范时只改相关部分，说明这是一种选择。

## 可用的练习方向

| 能力 | 练习示例 | 反馈重点 |
|---|---|---|
| 场景与进入点 | 同一件小事，分别从动作和对话进入，各写一个短开头 | 两种进入是否都让读者有线索，区别在哪里 |
| 用词与语气 | 保持事件不变，把同一句话写成平静、意外两种声音 | 变化来自哪些词，是否新增事实 |
| 节奏 | 同一等待场景写舒缓与急促两版 | 停顿和信息次序的效果，不按长短句数打分 |
| 重复与省略 | 一段中保留一次有作用的重复，删掉一次无作用的重复 | 是否能说清各自承担的任务 |
| 人物 | 同一困境里，让两个人做出不同而可信的选择 | 选择是否有具体处境支撑，不靠职业标签 |
| 修改判断 | 对一小段做必要修改，并保留至少一处自己认为不该改的文字 | 能否解释收益和保留理由；这只是练习条件，不是正文配额 |
| 深度改稿 | 对同一段分别试合并、重排或整句删减，选最适合上下文的一版 | 是否真正改变阅读效果，而不是只更换标点或以改字数量论好坏 |
| 文学再创作 | 从同一素材中改变一个人物选择，再回修前后的动机与后果 | 新情节是否成立；不要求与真实素材逐项相同，也不为反转而反转 |

字数或形式限制仅为本次练习安排，不能升级成文学标准。
评价维度随练习变化，不把文学水平化成一个通用分数。
对照经典作品或学习风格时分析可迁移的叙述距离、节奏和用词，不照搬故事、人物或长句段。
