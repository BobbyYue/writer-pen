# 写作判断：在语境中选择技法

按具体问题选择写法，相关改稿示例见 [cases.md](cases.md)。

| 关注点 | 有用的判断 | 常见误用 |
|---|---|---|
| 阅读 | 从喜欢的作品辨认声音、结构和材料取舍，再用自己的材料练习 | 模仿变成复制，或把一位作家的写法当唯一标准 |
| 选材 | 什么让自己受到触动，具体的人与处境怎样让读者进入 | 自己感动就认定读者也会感动；用抽象主题代替材料 |
| 开头 | 是否提供适合这篇作品的进入点 | 每篇都以异常事件开场，或一律禁止景物、对话开头 |
| 用词 | 动作、程度、频率和预期是否准确 | 替换近义词时改变事件或人物态度 |
| 关系 | 动作、对象、条件与指代是否容易恢复 | 为压缩而删必要连接；为“合理”而补造事实 |
| 节奏 | 句子落点、停顿和长短交替是否符合这一段的速度 | 用固定标点、句长配额代替阅读判断 |
| 重复 | 是否承担强调、人物声音、音乐性或结构对应 | 机械去重、每篇都重复结论 |
| 省略 | 读者能否从当前语境恢复被省略的关系 | 把作者常识当读者常识 |
| 情感 | 行为、变化、声音或直陈能否承载具体感受 | 堆形容词或先贴情绪标签；一律禁止直接抒情 |
| 人物 | 行为是否来自具体处境，是否允许矛盾和变化 | 职业刻板印象、统一的善恶或心理解释 |
| 段落 | 信息的重心、承接、分组与结束位置是否有效 | 每个细节各自正确，连起来却跑题；硬套结论—证据 |
| 体裁 | 短篇的集中、中篇的展开、长篇的方向分别需要什么 | 短篇必须无提纲、散文必须虚构、篇幅靠注水达成 |
| 改稿 | 新版具体解决什么，又损失什么 | 改过等于改好，越短越好；不允许恢复原句 |
| 声音 | 作者怎样观看生活、说话和安排距离 | 给所有稿件加同一种“文学感”，或把人物修成统一口吻 |
| 合并与重排 | 让分散的条件、动作和对象形成连贯场景，把重要信息放到合适的落点 | 只改停顿而不改组织；把一切倒叙都改回顺叙 |
| 删减 | 删除读者已能感到的解释，或正在冲淡段落重心的整句 | 只敢删虚词；反过来把情感直陈、幽默或比喻全部删掉 |
| 重新措辞 | 为动作、语气和节奏重写表达，既可以变短，也可以变长 | 只做同义词替换，或把所有主被动句式都当成等义 |

## 如何使用这些判断

需要具体调整段落边界时，读 [段落与停顿](paragraphing.md)：按动作、关注与情绪的推进
判断合并和拆分，不默认一句一段，也不靠统一减少段数改善节奏。

从眼前的一处问题出发，选择适用的写法。对已经成立的文本，不为了覆盖表格而逐项改写。
同一种写法可能有不同作用：重复可以拖沓，也可以建立节奏；不解释可以含蓄，也可以费解。
评价时说明具体上下文，不用“高级”“有质感”“更文学”替代理由。

“成立”不只是没有病句。文学改稿还可以追求更有分量的落点、更直接的动作、
更可信的人物和更集中的段落。允许虚构时，原始事件与声音都可以成为重新设计的材料；
让新增、删减与重排落实到作品中，而非只给外围建议。原稿事实不是虚构版本的验收表，
新版本内部的因果、人物动机和前后照应才是主要检查对象。

“像作家”不是统一风格。幽默、俗语、平直叙述、方言和不整齐的节奏，
若服务这篇作品，应保留；若连续机锋遮住了人物，或语气与新方向不合，也可以改。
比喻、感官细节、结尾议论都按作用判断，不建禁用清单。
