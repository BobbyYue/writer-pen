# 人物先行：从这个人出发，不从标签出发

起草、续写或实质改稿，在安排情节、挑选细节之前先分析主要人物。
只改局部时分析相关人物在该处的处境，不强制全套人物小传；没有人物中心的散文不硬套。
分析用于作出写作选择，默认不展示长表或思考过程。需要工作记录时留简短人物理解与文本依据，
用户要作品就先交作品，不让分析占据正文。
作者与专业审稿共用 [文学审读准则](literary-review.md#共用文学准则)；下文保留人物分析、封存和对照的具体做法。
其中 [反应程度](#反应的程度是否有支撑) 是该项的完整权威说明，方法包直接提取此段，不另存副本。

## 写前：从基础画像到具体选择

按五层理解主要人物，再选情节。维度通用，不意味着每篇填满；只展开影响当前作品的部分。
不凭空补齐年龄、收入、家庭创伤或心理诊断，未知与不相关可以直接标明。

| 层次 | 分析什么 | 怎样影响写作 |
|---|---|---|
| 1. 生活基础 | 人生阶段、职业与经济条件、居住环境、身体状态、家庭与重要经历 | 看这些条件怎样影响机会、限制、生活节奏与经验；不从身份直接推出性格或习惯 |
| 2. 内在倾向 | 在意什么、想得到什么、顾虑什么，如何看自己，通常怎样应对；相反表现是什么 | 形成具体的欲望与矛盾，不以内向、善良等形容词替代行为；一次反应不自动成为恒常习惯 |
| 3. 关系画像 | 与重要他人的亲疏、期待、依赖、主动权、误解；在不同人面前如何不同 | 决定他对谁敢说什么、回避什么；人物在不同关系中的差异不自动算不一致 |
| 4. 当前处境 | 什么触发事件，当时知道或误会什么，有哪些选择及代价 | 决定场景中的注意、反应和转变；不让人物提前知道后文，也不要求人人理性选择 |
| 5. 文学呈现 | 叙述视角与距离、人物声音，哪些行为、细节、反复或留白值得呈现 | 让读者经历人物而非读一份分析；人物如何感受自己与旁观者如何评价应区分 |

各层都从材料中的行动、台词和反例出发，也记录尚不能确定的理解。
可用几句建立写作起点：他想要……，却顾虑……；材料中的……支持这种理解，……又让它不那么简单。
本版准备让他面对……，观察他会如何应对。分析可以比正文宽，正文不必展现全部画像。
主要人物之外，只分析与当前事件相关的配角动机，不给所有人强补完整人物弧线。
关键场景还要记住关系到了哪一步、已有何种互动和积累、此人的欲望与顾虑怎样影响反应。
材料尚不足以支持很强或很具体的反应时，保留判断中的未知，不先为某句写法补出一套性格。

内部区分三类信息：**材料给定的行为与事实、暂时的人物解释、本版可调整的艺术选择**。
艺术选择包括虚构设定、叙述距离、情绪表达与结尾，不是材料事实或人物定论；解释须容纳反例与其他可能。
本版写作依据记入 `writing_basis`，记录要求见 [写作记录](writing-quality-records.md)，此处不另列格式。
一处职业比喻只能提供有限线索，不能直接推出职业、生活习惯和对他人的表达方式。
材料稀少时，可建立必要的新设定。不得把想象写进原材料的人物分析，
再拿这份分析给同一想象作证。更换人物或视角时重做相关分析，不把上一版本的发明当成原文事实。

## 起草之前：封存本版人物分析

完成分析后、开始本版正文前，将简短的分析记录保存到当前任务的本地工作目录。
记录至少包含作品与稿次、记录性质（写前、写中调整或事后整理）、素材版本或定位、叙述范围、用户明确限制、主要人物五层分析，
并区分给定事实、暂时解释和可调整的艺术选择。为影响重要选择的判断加简短编号，方便写后指认。
封存的是这些可核对的判断与依据，不是逐步思考过程，也不要求把所有构思都写入记录。
它保留写作起点与后续差异，不把解释当定论，也不强迫正文兑现预定主题或克制风格；选择调整时按下文另存版本。

优先使用本包的 [封存脚本](../scripts/character_record.py)，把文件复制为不覆盖的快照并记录实际时间及摘要：

```bash
python3 <skill-dir>/scripts/character_record.py seal <人物分析.md> <任务目录>/writing-records/<作品>/<版本> --id character-v1
python3 <skill-dir>/scripts/character_record.py verify <任务目录>/writing-records/<作品>/<版本>/character-v1.record.json
```

- 多个小说版本分别封存各自设定；共享材料可引用，不把A版新增设定当成B版原事实。
- 已存在的编号不得覆盖。需要调整时保留旧记录，使用新编号，并在新分析中注明旧版本、改变原因和影响范围。
- 起草期间形成的新版本要如实标为写中调整；写后才补的记录标为事后整理，不倒填时间或冒充写前封存。
- 重新从原文写，也新建本轮记录；不继承旧稿虚构为原始素材，不删除历史记录来隐藏差异。
- 只存当前任务获准的本地目录，不写入 skill、全局记忆或可发布资源；用户要求不落盘时遵守，并说明无法完成文件封存。
- 运行环境不支持脚本时，用工具独占创建新文件、保留可核对副本与时间；无法核验就报告未封存，不声称完成。

脚本拒绝覆盖、检查内容摘要；它不是不可篡改存储，也不能证明分析真的早于写作或证明人物合理。
必须实际先封存再起草。不要把有快照误当成已执行了写后人物审读。
实质写作有本地记录权限时，将封存件登记到 [本轮执行记录](execution.md)，使稿件、写后对照与各自基准对应。
实际生成顺序仍须由调用入口约束，本包的登记顺序不能单独证明它。

## 写中：从人物走到场景与细节

先考虑这个人此时会注意什么、想做什么、敢做到哪里，再决定用哪些事件、动作、对话和物件表现。
关键场景应能辨认：当前处境触动了什么欲望或顾虑，人物如何反应，反应带来什么后果。
这不是要求在正文解释全部心理；只要读者能从足够的线索相信其发生，也允许暧昧与意外。
不要先设计漂亮结尾，再让人物为到达结尾做出缺乏支撑的行动。

对承担人物塑造或关系变化的细节，分别判断两件事：

1. **人物会不会如此。** 在这个时刻、面对这个人，他为何会这样说、做或留意？依据是具体处境、
   已有行为或本版连贯的虚构设定，还是只有“这种职业的人大概如此”“他就是内向”一类标签？
2. **作品是否值得这样写。** 即使合理，读者从正文实际多经历或感受到什么：关系变化、气氛、声音还是人物层次？
   若只是在已有职业或性格标签上再贴一个道具，考虑删除、换写或让它承担更具体的作用。

“可以解释为符合某类人”不等于“符合这个人物”；“符合人物”也不自动等于“值得占据篇幅”。
叙述者关注某物和人物主动做某事是不同判断，不能因为细节有象征作用就让人物配合摆弄它。
中性的环境、气氛和日常过渡不必逐项证明人物功能，但不应与已建立的处境冲突。

### 反应的程度是否有支撑

对有疑问的关键心理、情绪或行动，先核对这个人会不会反应到这一步，再看它能表现什么。
用必要上下文回答四个问题，不逐句填表：

- **触发与积累是什么？** 此刻实际发生了什么，人物此前经历了什么、误会了什么？微小触发也可能唤起强烈反应，须结合已有积累判断。
- **关系与认知到了哪一步？** 彼此熟悉多少，已有怎样的互动，人物知道与猜测什么？不能只凭“多情”“胆小”“爱幻想”等标签跳过具体处境。
- **反应写到了多远、多实？** 强度、持续时间、涉及的未来和具体筹划，是否超出了已建立的人物？一闪而过的念头、反复盘算与实际行动是不同程度。
- **离开创作说明还信不信？** 暂时去掉“为了突出性格/制造反差”的解释，只读正文，找能支撑这一次反应及其程度的文字，也看反证。

“我想、我觉得、我以为”只说明念头归谁；“能表现自作多情/焦虑”只说明表达用途。
两者都不能代替对反应是否可信的判断。多写几个具体步骤，可能把轻微联想变成强烈执念，改变读者认识的人物。
原材料中的口语自嘲或概括性夸张，改成写实场景时重新判断；不能机械展开为地点、流程和应对说辞，并沿用原句的成立理由。

支持不足时，实际比较原处理与试删、缩减过度筹划或另一种反应，选能承载同样人物作用的自然写法。
已有细节足以表现期待、误读或担忧时，可以直接删去强化句，不要求一定补一个更漂亮的细节。
也可以展开更强的反应，但要有值得发展的故事与人物需要，回修前后联系；不为保住一句话追加身世或巧合。
反应不必越弱越好：强烈情绪、执念、喜剧夸张、荒诞和不可靠叙述，按已建立的人物与全篇声音判断，不统一改成温和克制。

例如，知道一个人是图书管理员，并不足以写他给每位客人的杯子贴编号。
若本版建立他在聚会中怕认错人、又不敢开口问，贴姓名的举动才可能来自具体处境；
是否真的采用，仍要比较它是否过于刻意、是否比直接问话更符合这个人，以及是否值得停留。
不要为保住一个薄弱细节，连续补出一串身世或习惯作为借口。

人物不必永远一致。矛盾、失常、冲动或反常选择可以成为故事，但须让处境与变化可感，
不把“不符合最初标签”当成自动删除理由。试写发现人物更复杂时，修正原来的理解与前后文，
而不是把正文修回一份僵硬的小传。对写前分析的修正另存新版本，不覆盖封存的基准。
允许虚构意味着可以重塑人物，不意味着免除内部可信度；用户明确固定的设定不能擅自改写。

## 写后：先从正文识别人，再回看写前分析

接入 [净稿通读](read-through.md) 与 [版本比较与取舍](revision-evaluation.md)，不另加一套检查数量：

- 先只读正文，概括人物想要什么、如何应对、有哪些矛盾，并指出实际文字；不能照抄写前分析。
- 核验并读取写前封存件，比较写前理解与读后人物：是作品发展了更可信的复杂性，还是新增情节把人写偏了？
  封存件缺失或校验不符时先披露，不能拿新整理的分析充作原基准；仍可按正文完成有限审读。
- 对关键新增或存疑细节，按 [共用准则](literary-review.md#共用文学准则) 定位问题，引用必要场景与反例，
  不复述写前标签当作读后发现。
- 对程度存疑的反应，连读触发与反应，按 [权威段落](#反应的程度是否有支撑) 逐项核对；引用触发和支撑/反证，不能只摘反应句。
- 只有旁注能解释、正文却支撑不了时，修改或撤回该处；确有文学收益才补必要前提，不一律追加解释。
- 按现有 A1/A5 检查人物行为与细节，C1 用正文证明人物，E4 保护矛盾与复杂性；存疑取舍使用 D1—D4。
  编号用于定位问题，默认不逐项打分。写前理解是待对照的解释，不是人物只能照办的答案。
  修后重读受影响的前后关系，不以完成分析或得到高分作为人物已经可信的证明。

在独立的写后检查文件中记录基准文件与编号、被检查的正文版本，以及关键判断对应的正文短引或段落位置。
分类处理：符合原理解；正文新增但原分析未涉及；有依据的人物发展；缺少支撑的偏离；背景不必在正文显露。
后两者不能混为一谈，未写出履历不等于人物违背画像。
有依据的发展要说明触发、反应、前后联系和所得所失；偏离则改正文、撤回细节，或在权限内修订设定并回修全文。
只说符合人物或只给分数不够；不能为了让稿子通过，把旧分析改成与成稿一样。
新分析不能抹去最初偏差：保留与原封存件的差异、采用理由，再核对最终稿是否兑现新版设定。
