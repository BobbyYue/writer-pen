# 创意文案：独立写作场景

用于主题创意、叙事文案、角色对话，以及品牌或活动的创意表达；载体可以是纯文字、图文、声音、视频或现场表演。
不要求先有视频用途。小说、散文仍走文学流程；本场景不扩展为常规促销、带货、投放广告或媒体制作服务。
学习的是材料的创意组织，不复制某位作者的原句、人物配对、标志性结尾或整套表达外形。
人物中心的文案遵守入口的 [共用创作取向](../SKILL.md#共用创作取向)：充分呈现各自的处境、欲望、价值排序、声音与局限，
不预设统一的人生答案，也不以受众站到同一边为完成条件。没有人物的主题、海报等文案不为此硬编人物或对立。

## 场景边界

- **与纯文学分开：** 小说、散文不因需要节奏、对话或画面感而进入本场景。
  本页不改写其人物封存、文学审读清单或写作标准；小说改编稿与原小说分别保存。
- **不强套小说流程：** 本场景不要求五层人物画像、人物文件封存或逐项填写纯文学审读记录。
  理解相关人物和关系是构思动作，不等于启动小说流程；没有人物中心的主题文案、海报短句不硬编人物与情节。
- **按内容性质处理：** 虚构、神话或历史演绎按本篇设定判断可信度；纪实人物和品牌事实按已核实材料写，
  不编造真实经历、成效、产品功能或承诺。典故的出处、演义版本和本次戏说不能混当史实。
- **不预设载体：** 用户要文字就交文字，不默认改成口播或视频脚本，也不先追问时长、镜头、配乐和画面。
  只有相应的声音、视频或表演任务才检查时长、音画分工和节拍；只有要求脚本时才加入制作安排。
  写作要求与内部比较留在正文之外，必要的角色名、台词归属与受众需要的说明可以保留。

## 核心能力

| 能力 | 实际要完成什么 | 不是在做什么 |
|---|---|---|
| 切入角度 | 从材料中选择值得关注的人、关系、争议或问题；视角改变应带来新的认识 | 为反常而反常；所有故事都替反派翻案或转向受害者 |
| 立场与关系 | 让各自的经验、利益、顾虑与关系影响说话姿态、选材和表达顺序，不只分配不同观点 | 用同一套逻辑替不同人物自证；用标签分配正反方；单句文案也强造对立 |
| 材料转化 | 使事件、典故、物件或经历参与行动、自辩、攻击、回应或情感发展 | 堆知识、搬名句、先写金句再替它找理由 |
| 信息分量 | 让主要段落带来足够的具体经历、关系、行动、选择或认识变化；人物怎样挑选和讲述材料也是信息 | 用抽象态度撑篇幅；以专名数量或优点覆盖冒充信息量；给每人配齐一份正面履历 |
| 贯穿联系 | 让一个问题、动作、物件或意象在不同位置获得推进、反差或新的含义 | 反复说同一句话；让所有道具都成为象征或结尾伏笔 |
| 表现形式 | 按阅读、口播、对话、演唱与音画分工组织文字 | 把所有文案写成微型小说、说唱或分镜清单 |

## 写前：确定材料怎样成为作品

### 1. 明确任务与素材

确认用途、受众、形式、长度或目标时长、已知人物与事实、可以虚构的范围。
用户已经给出的不再问；未指定时可选择合适方向，不把每个创意选择交回用户。
只处理当前载体需要的信息。纯文字不换算成秒数；声音或表演的长度与时长不是同一要求，未实际试读时只给估计。

有本地记录权限时，留一份简短构思笔记：素材与限制、采用的切入角度、核心关系、组织线索、表现形式及待核实事实。
信息密集的作品同时简记主要段落准备使用哪些具体材料、各自增加什么；人物中心的材料从当场表达行动出发，不先列能力清单再补战绩。具体方法随角色或说唱任务读下方专项方法。
不另做全套人物档案，不保存逐步思考过程；用户不允许落盘时在当前任务内完成，不声称留有文件。

### 2. 选择有依据的切入角度

先看材料原本让人注意什么，再考虑这一次值得多看见什么：

- 同一事件，对不同人各有什么意义、收益或代价？各自最不愿牺牲什么，哪一面在通常讲法里被略过？
- 人物在争什么、等待什么或坚持什么？同一件事为何会得到不同解释？
- 哪个具体愿望、关系、动作或表达联系能让受众进入，而不是先接受一个抽象主题？
- 能否用不同距离、讲述位置或表现形式，让现有材料产生新的联系？

题目开放或现有方向平庸时，实际试出有竞争力的切入句或小段，比较各自让人进入什么、需要补什么、失去什么。
不要求每篇凑固定数量，不默认向用户展示候选；用户已固定视角或只让改一段时，不擅自重做全篇创意。
人物中心的表达按 [人物怎样开口](dialogue-and-rap.md#1-写前先决定这个人怎样开口) 确定当场的表达行动，再选段落结构。
共同目标不要求共同的论证方式；受众与决策权未给定时，不因人物关系擅自指定裁决者，也不统一改成向某人求情。“观点不同、事迹不同”不能代替“这话符合此人之口”。不要先列统一提纲，再更换人物名和典故。
完整作品选定方向后先拟工作标题，再成稿复核；已有或固定标题可沿用，明确无题时不加题。
仅要一句文案、标语或标题时，按局部交付，不为填写完整结构另加题名、故事与首尾。

### 3. 使材料承担具体作用

选出对本篇重要的材料，决定它在这里怎样发挥作用：建立关系、推动行动、提供反证、改变理解，或形成回响。
引用和典故先读懂语境；能认出出处不等于已经转成了表达。把知识直接删掉后若只少了装饰，考虑改用或舍弃。
按受众熟悉程度选择典故展开量：可只取与主题相关的个人贡献、关键动作或影响，不必交代全部经过；陌生且确实妨碍理解时再补必要联系，不把正文变成注释课，也不让关键判断依赖观众猜测。
信息量是本场景成稿要核对的质量要求：按篇幅、受众和表达目的选择足以承载作品的具体内容，不用空泛态度和同义反复把稿件填满。
用户要密集典故或参考作品以连续经历见长时，实际展开多项有区别的材料；由人物在意的事、讲法与关系承接，不把增加信息落实为逐项补齐优点，也不退回单个事件反复论证。选材、解释和补充的收益代价见 [台词的内容改稿](dialogue-and-rap.md#3-内容改稿把讲解改成当场的台词)。
极短文案、有限事实、留白或有意复沓按实际用途判断；不向它们硬塞典故，也不以资料不足为由编造纪实事实。

需要贯穿线索时，写清它各次出现发生了什么变化：第一次让人看见什么，中间怎样改变关系或理解，最后留下什么。
这只是构思线索，不要求三次出现、闭环收回或结尾重新定义；连续观察、片段和开放收束也可以成立。
意象不能代替人物动机，不为保住漂亮联系而强编巧合或事实。普通过渡和环境不必逐项解释象征意义。

## 写中：按表现形式组织

| 形式 | 重点动作 | 容易出现的偏差 |
|---|---|---|
| 纯文字或图文文案 | 让切入、措辞与信息关系共同完成表达；图文任务才考虑标题、图中文字与说明的分工 | 自动加镜头或配乐；没有依据却假定图片已经替正文传达内容 |
| 叙事文案或个人表达 | 让具体关系、愿望或经历承担主题；根据实际载体判断哪些已呈现、哪些仍需说清 | 过程只剩概述，末尾突然宣布感动或意义 |
| 角色对话或对决 | 先写出人物当场想对听者做什么，再让选材、顺序、措辞和停顿实现它；具体做法见下方专项方法 | 用伦理辩论代替人物；把人物分析塞进台词；换名与事迹后仍是一份相同的自荐或辩护 |
| 说唱或韵文 | 先让具体材料形成有分量的段落，再做声音改稿，核对韵脚、重音、停顿及适用的呼应 | 把散文分行当说唱；材料单薄只靠重押韵；为了韵脚扭曲语义 |
| 品牌或活动创意文案 | 让产品、品牌或活动与具体关系、体验、问题或表达联系发生作用；事实只用已给定或核实的材料 | 空泛赞美；为没有故事的短文案强编情节；虚构效果、参数与承诺 |

对决以完整人物段落和整篇对照为组织单位，不默认每段都是问题与答案；一人一段、自由呼应或短回合都可，
自夸、讲述战绩、戏谑、回避和故意不接招也能呈现人物。只有作品选择问答式攻防时才检查逐轮接招，不将它强加给所有角色文案。
角色可以宣称自己正确、嘲笑对方或有矛盾与不一致；作者不因此替读者宣布统一胜者，也不为公平给另一方强补一轮反驳。
先让各人的表达成立，再决定哪些地方呼应、攻击或转向；既不先套“质问—反驳—再质问”，也不让独立段落都变成“承认不足—列举贡献—证明不可替代—金句收尾”。
这些结构并非禁用，问题是没有人物或形式依据却统一套用；一人一段不等于每人同一提纲，不为显出差别强行给每人分配一种修辞。
用户确实要求正式辩论时才以论证和回应为主要结构；battle 中有辩驳不等于必须写成辩论赛。
历史人物穿越、神话或喜剧夸张按已建立的文本或表演设定写，既不强求古人逐字使用古代口吻，也不把人物变成无差别的现代吐槽机器。

可按需要让一句话同时承担人物、关系、观点、节奏或情感的作用，但不要求每句多义、用梗或成为金句。
直接表达和概括句不自动判差：检查前面的具体经历是否赋予它分量，还是换一篇仍能套用而没有新增意思。

**角色对话、battle、说唱或韵文起草与改稿时，读取 [台词与说唱改稿](dialogue-and-rap.md)。**
角色台词做解释检查；说唱另做逐段声音改稿，rap battle 两项都执行。不把这些检查变成小说流程，也不向其他文案强加对决或押韵。

口播先按发音与口语顺序核读，辨认听众第一次听是否能恢复关系、重点和转折。
没有伴奏也要完成适用的韵脚、重音和停顿组织，不能因未试唱而省略文字层声音改稿。
有伴奏或明确节拍时才进一步核对具体落拍与换气；没有实际音频或试唱，不声称已经听读或完成演唱适配。
用户只要文字时不替其生产音视频，也不擅自上传、发布或调用付费制作服务。

## 写后：独立于纯文学的检查

先暂时放开构思笔记，连读当前完整文案；再按实际适用项检查，不要求每项对应一张表或一个问题。

| 检查什么 | 从当前稿找什么依据 | 存疑时怎样改 |
|---|---|---|
| 切入是否实现 | 受众实际多理解或感受到什么，而不只在创作说明里新颖 | 试换进入处、讲述位置或缩小命题，再看必要上下文 |
| 人物与关系是否具体 | 从整段能否辨认各自的经历、欲望、价值排序与局限，关系怎样影响表达；不是只分出谁更有理 | 回到人物与材料重写，不默认增加质问、认错、握手或判词；立场差异不必消除 |
| 台词是否属于人物，适用于角色对话与对决 | 不看构思笔记，能否从说话姿态、选材及顺序看出这个人；跨人物比较是否只换了姓名、事迹和自称 | 按 [换人比较与结构检查](dialogue-and-rap.md#5-回读与记录检查必须指向当前文字) 找到同质化处，回到人物的当场意图试改；不只加口头禅、强行制造缺点或逐句反击 |
| 材料与信息分量是否足够 | 逐个主要段落有哪些具体内容、新关系或新理解；讲述者的偏重是否可感，还是只配齐贡献、优点和解释 | 先从当场口气和材料取舍重组；对存疑补充实际比较删留或换讲法的得失。保护密集而有效的经历及理解前提，不以补全能力或统一删短验收 |
| 联系是否发展 | 相隔两处的联系带来推进、反差或积累，还是重复同一个意思 | 连读相应位置；可压缩、换位、展开，也可取消刻意回收 |
| 形式是否合适 | 普通文案的信息关系；口播的首次理解；说唱各段实际的韵脚、停顿和重音组织 | 按专项方法回看当前稿的具体句尾与断句；散文分行不能代替声音改稿，实际落拍另按音频条件核对 |
| 表达是否属于这篇 | 重要台词、总结和结尾是否由本篇关系与经历支撑 | 放回前文比较，保留有效直陈，删除或重写空泛升华 |
| 标题与首尾是否相合 | 标题带来的期待、开头的入口、结尾留下的理解或感受 | 工作题与候选在同一正文上比较，不必强造反转或金句 |
| 事实与修改范围是否守住 | 真实材料、演绎、新增设定与明确约束；已改处的前提和后果 | 核实、缩小、标明演绎或撤回，不用创作说明替正文补证 |

有实际问题时试出改法，比较收益与损失；修复后回读受影响联系，并再读最终稿。
检查通过不证明受众一定投入或作品会流行，不用总分、传播效果推测或与某作者的相似度裁决质量。
不因作品没有人物冲突、镜头、时长或音频就判为不完整；这些要求只在实际适用时启用。
没有音画材料时不把配音、表演和音乐的预期效果当成文字已实现的效果。
需要外部反馈时只提供当前文案和中性问题，不给预设答案；未实际获得的反馈不写成“独立审读通过”。

## 交付与记录

- 默认先交一个完整可用稿；有实质方向分歧或用户要求时再给多版，不用同义替换凑版本。
- 完整文案默认离线HTML，短文案、单句、标题与方法问答直接回复；明确聊天输出、纯文本、脚本格式、现有目标或不落盘时优先遵守。
  用本包 `render_html.py` 与 `validate_html_output.py --text` 复用排版与逐字核对能力，
  页面依 [HTML的实际检查](html-output.md#真正打开页面检查) 核对桌面、手机和打印。
  这些是格式与呈现核对，不启动或冒称通过纯文学受管审读；不伪造其人物封存、审稿记录或完成标记。
- 文案本身先读；创作理由、事实来源、待核实项，以及适用的时长估计和音频检查范围按需要放在正文之外。
  角色名与受众需要的演绎提示不算无用的制作说明；用户只要正文时，不塞进选题理由或检查清单。
- 允许本地记录时，保留本次构思、当前稿和关键修订短记。检查只声明实际完成的范围；
  文案完成不等于视频制作完成，静态HTML通过不等于已看过页面，预计可演唱不等于实际落拍。
- 本场景的稿件、检查与修订单独保存，不替换小说的记录，不用于消除已有文学任务未解决的问题。

便捷生成器的输入为纯文本：首行题名，空一行，再放正文，空行表示段落；不要夹带Markdown标记。
用户明确不要标题时，输入只有正文，以下两个命令都加 `--untitled`。

```bash
python3 <writer-pen>/scripts/render_html.py --text 文案.txt --output output/作品/文案.html --lang zh-CN
python3 <writer-pen>/scripts/validate_html_output.py output/作品/文案.html --text 文案.txt --expected-language zh-CN
```

`static-checks-passed`只说明格式和文字对应，不是内容或页面审读结论；生成后仍须实际打开检查。

## 合成例子

以下只是方法示意，不是名家原句、真实事件或可套用的固定模板。

**同一件事，不同的解释。** 虚构小站要撤去末班车的五分钟等候。
司机在意整条线路准点，值班员担心从医院赶来的人再也接不上车。
可以让双方围绕同一次迟到交锋，而不把司机写成冷血、值班员写成唯一好人。
若用户要的是安静小说，不因为这个例子就把它改成舞台对决。

**物件不只重复出现。** 虚构修伞摊交接给女儿。
同一把旧伞第一次用来撑住摊棚，后来女儿发现伞骨与自己修的那根不同，末尾可落在她如何处理这处差别。
是否采用取决于人物与场景能否承载，不预先宣布它象征传承，也不为三次出现强编损坏与巧合。

**纯文字也能完成创意。** 虚构旧书交换活动，只知参与者可带书互换。
可从书被不同人读过的联系切入，例如“你读过的那本，轮到别人翻页。”
这是一句文字表达的示意，不要求补人物故事、视频镜头或配乐，也不承诺活动还有未给定的服务。
