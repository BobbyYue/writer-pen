# 人物特写：在处境与关系中写人

用于真实人物的特写、传记式人物稿及其改稿。沿用 [创意文案](creative-copywriting.md) 的流程与交付方式；本页补充选材和审读判断，不另建一套写作程序。仅要求诊断或局部修改时，保持该范围。

目标是让读者从具体经历中认识这个人怎样选择、回应和与人相处。履历、成就与项目背景按理解需要交代；一段只增加对项目的了解、没有增加对人的认识时，考虑压缩或换材。

## 写前：选择能显出人物的材料

在现有构思笔记中回答：**只看履历，读者容易怎样理解这个人？哪两三处有出处的材料，让这种理解更完整？** 由此提出一个还值得追问的问题。少量材料或平静日常，一个有分量的片段就够。若只有奖项和赞誉，先找本人如何选择、熟人看见过什么；查不到就缩小题目。年表用来校对先后，篇章围绕人物组织。材料可以增添另一面，不必推翻履历印象，更不为获奖者安排一段低谷。

| 从哪里找 | 选材时判断什么 |
|---|---|
| 人物所处的位置 | 他想做什么、被期待做什么、实际能做什么？空间、衣着、称谓、座次或谁能发言，有没有让这种处境可见？只使用确有意义的细节，不给每个物件附会象征。 |
| 与人的交往 | 一次争执、求助、拒绝、教导或没有得到回应的认真，能否显出他怎样对待别人、又被怎样对待？选有个人反应的片段，避免只用他人的赞誉代替关系。 |
| 同一行为的多面性 | 慷慨与舍不得、自信与受挫、体面与窘迫，是否在同一件事里并存？保留材料中的复杂性，不为“立体”补一个缺点，也不为同情抹去局限。 |
| 前后变化或持续 | 同一种动作、说法、习惯或关系，在不同处境中有什么改变？后一次是否使前一次有了新意味？没有可用的前后对照，也可以写一个充分展开的片段。 |

不要求人物必须陷入冲突、经历低谷或最后成功。平静日常也能显出人；选择哪种材料，由本篇的认识价值决定。

**纪实材料的用法：** 区分现场记录、当事人回忆、他人评价与作者推断；保留必要的归属和来源。公开资料没有记下的对话、动作、天气、内心或劝说理由，不能为使场景完整而补造。可以换用记录更充分的片段、压缩该处或补问；不借“文学创作”说明把编造混入人物事实。

## 写中：让反应与关系发生

- 展开一段合作或分歧时，分别弄清双方在意什么、各有什么理由；写出一句话或一个举动怎样被接住，判断随之改变还是仍有分歧。只有共同署名、会议次数或旁人赞誉，最多能说明他们有来往。材料只记下一个人的动作，就写到那个动作，不替另一方补反应。
- 让语言属于说话者：他此刻在争取、拒绝、掩饰、解释还是求助？保留有依据的语气和局限，不把作者的人物分析改写成漂亮台词。没有原话就转述，不制造引号内的“本人声音”。
- 给关键经历足够篇幅，让读者看到选择怎样发生；一般背景和过渡可以概述。不能把所有事都压成等长的小段，也不因追求厚度复述全部过程。
- 展开科研、工作或历史事件时，围绕人物的判断、回应和代价选择细节。术语和过程只保留到足以理解这一行动，避免又写成项目成果介绍。

## 组篇：让材料彼此改变意味

确定叙述者从哪里知道这些事，以及读者能通过他看见什么。本人回忆、旁人见闻和记者整理可以采用不同距离；转述中的判断不自动变成事实，也不要求作者在每次互动后出面判定人物。

通过取舍、关系或处境的延续组织全文。反复出现的动作、声音或物件可以形成照应，但每次应带来新的理解、感受或节奏作用；不设出现次数，不为闭环制造巧合。空间和环境可以承担关系，不必都写成风景段落。

写转折时，区分“后来发生了什么”与“这个人为什么改变选择”。关键联系有记录就写清；没有记录时，不把时间相邻写成心理因果。开头提出的主要疑问应有回应，或让未能确定的部分保持可辨。

结尾从前文已经形成的关系、变化或缺席中收束，可以落在动作、原话或尚未完成的选择上。不要用新增的品德评价、人生道理或获奖结果替全文盖章；有必要的议论和直接收束仍可保留。

**每章写完，先遮住标题。** 只读正文：这个人做了什么，读者由此多知道了什么？再看章名。例如“交出证明”写出解题能力，“请老师给一道这类题”写出兴趣；若章名是“选题”，还得看他决定先做什么、搁下什么。题文对不上，优先补有依据的取舍或收窄章名；章名固定则补写正文，资料不足就说明缺口，不让一句性格评语顶上。无题短稿按自然段落的作用判断，不为检查硬设章节。

若只能复述项目进展，把专业背景压到足以让读者理解当时的判断和代价。遇见好细节，再问“放在这里改变了什么”：一句家常话若能纠正对前后事件的误读，就留；有趣却截断关键选择，可以移到更合适的一节或旁记，无处安放再删。

## 表达：判断解释的作用，不按词删句

心理描写、概括和议论都可以写。区分人物有依据的自述、叙述者的判断，以及作者为怕读者误会而追加的说明。

对可疑句，放回完整段落比较保留、删除和直接改写：

- 如果行动、原话与上下文已经充分呈现了意思，后一句只再次命名情绪、宣告性格或总结意义，可以删去。
- 如果删后失去关键条件、消息来源、行动联系、必要时间地点或有用的叙述声音，应保留或重写，不以“留白”掩盖理解缺口。
- 真实的心理自述可以增加动作没有提供的信息；不把“不安”“犹豫”或“信心”等词列入禁词，也不为改成动作而另造一幕。

删后通读相邻段与全文。少解释不等于只留事件清单；压缩若使取舍过程消失、段落变碎或人物变薄，要恢复必要内容，或重新选择展开处。

## 写后：只凭正文认识人物

沿用一次全文通读，不靠构思笔记补意思。按本篇实际需要核对：

| 要回答的问题 | 怎样查，发现问题怎样改 |
|---|---|
| 读完认识了怎样的人？ | 用自己的话描述，并指出具体文字。区分正文支持的认识、读者暂时推测及尚未呈现的方面；缺证据时补材料或收窄评价，不加性格标签。 |
| 写出了人，还是只写了事？ | 看读者记得的是人的选择、反应和关系，还是只有履历与项目结果。将最有表现力的互动展开，其余按作用取舍；不要求每个细节独一无二。 |
| 关系有没有真正发生？ | 人名出现、获得帮助或“受人鼓励”不等于互动已经写清。检查人物如何回应彼此；标题承诺写合作或亲情时，正文是否兑现。 |
| 段落能否共同推进认识？ | 看前后材料有何联系，关键决定与后果是否接得上。相邻事件不自动互为原因，重复特质不等于递进；重组关系，不只加过渡词。 |
| 心理与解释是否恰当？ | 用上节的删留比较，保护有信息的心理、必要说明和叙述声音。发现理解缺口时补事实联系，不机械补一句情绪判断。 |
| 开头与结尾是否成立？ | 开头是否使人愿意认识这个人；结尾是否由已写出的经历获得分量。事实缺口与有依据的开放结局分开，不强求感动、反转或统一人生答案。 |

把两种视角放进原有通读，不新增轮次、分数或对外表格：

- **编辑看转折。** 对照原始记录、采访或作品本身，逐处核对支撑主线的取舍：是谁在何时作的判断？暂时搁下的是整条路，还是其中一步？材料与提纲不合，改正文及受影响的章名、照应和结尾；保留当时尚可走的路，不用后来的结果倒推动机。
- **读者看净稿。** 不给提纲和目标性格，先问：“你记住了这个人的哪一次选择、反应或相处？哪一处文字让你这么看？”只记得奖项或项目时，回到最能写出人的一幕，重选、展开或换位置，不追加道理。读者有不同但有正文支撑的理解，允许并存；读懂却无感也如实保留。只有作者自查就明确为自查，不冒充独立反馈。

## 方法参照

以上是对鲁迅 [《孔乙己》原文](https://zh.wikisource.org/wiki/孔乙己) 的写法提炼，不是鲁迅本人列出的写作规范。可对照衣着与站位、教字时的双方反应、分豆与护豆、前后付钱的动作，以及笑声和欠账的反复，理解细节怎样在关系中改变意味。学习这些组织方法，不复制其人物、情节、冷峻口吻或悲剧结局。

小说可以设计典型场景，纪实人物稿需要先找到真实材料。这里迁移的是选材和叙述判断，不是虚构许可。
