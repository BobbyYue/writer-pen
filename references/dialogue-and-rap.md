# 台词与说唱改稿

只在已经选择创意文案场景的角色对话、对决、说唱或韵文任务中读取。
普通对话做台词检查，不自动变成 battle；说唱做声音改稿，rap battle 两项都做。
人物呈现优先于驳倒观点：让话出自人物当下的处境、关系与表达意图，不先选一道伦理题让他们争标准答案，也不先套统一提纲再填入不同人物。
一人一段、自述与自由呼应、短回合都可以；不固定形式，也不要求每句话都有对手必须回答的攻击。
先决定这个人会怎样开口、接着说什么、停在哪里，再组织段落和呼应；独立人物段落不是统一的自荐书或论证模板。
正式辩论是用户可选择的形式，不是 battle 的同义词；有攻击性也不等于句句逼问、对方句句答辩。
用户明确不要押尾韵时遵守，改用重音、停顿、复沓或内部呼应组织节奏。
小说散文、普通品牌文案不沿用本页作为强制标准，也不因这些方法取消明确的原文保留要求。

## 1. 写前先决定这个人怎样开口

在已有构思笔记中留下足以指导本次台词的选择，不另建人物档案，不按下表逐项写心理说明：

| 从什么出发 | 要影响的实际写法 |
|---|---|
| 受众、决策权、所知与处境分别是什么 | 听众不等于裁决者，不因师徒、长幼、职衔或亲近关系默认谁掌握去留；未给定时可公开自陈或面向在场众人，不必虚构上级、评委或固定收件人。区分双方已知与新信息，不让人物忽然掌握作者的全局认识 |
| 想争取什么，真正怕失去什么 | 可以是同一个目标，也可能嘴上谈功劳、实际怕丢脸或失去同伴；不强制每个人都有隐秘动机 |
| 想让听者怎样反应 | 求情、震慑、套近乎、翻旧账、讨价还价、回避或讲明道理都可选；这是当场的表达行动，不是固定性格标签，也不要求每人各用一种 |
| 会挑哪些旧事，怎样讲 | 同一件事对他是功劳、委屈、羞辱还是笑料？他会夸大什么、略过什么、向谁邀功或不肯解释什么？保留既定事实，角色的理解可以偏心 |
| 怎样开口、转向和收住 | 按关系与当时反应选择措辞、长短、重复、改口和停顿；结构从此人的表达长出来，不预先统一开头、证据段和收尾 |

先试出能带出此人的开口或短段，再顺着他的材料选择与表达行动展开，不先为所有人分配完整的同款提纲。共同争取留下、获胜或被理解时，写的是他们各自怎样争取，不由作者替每个人证明得周全、无可指摘。
人物说话本身应让读者感到他在争、躲、哄、撑、解释或犹豫。主题要求说明自己对共同目标的价值时，应当说清实际贡献，可以自信直陈、自夸或讲理；不必转成对某人的求情，也不为躲开价值总结而把主题写成无关的生活片段。
“同一目标”“各讲一段”都不等于“用同一逻辑自证”；不默认每人都先承认不足、再摆事迹、再证明不可替代、最后送一句金句。

这些选择帮助写台词，不逐项塞进正文。人物可以连续自夸、报家门、回忆或表演，也可以狡辩、逞强、装客气；
不因没有逐句接招就删掉。人物不必准确理解自己，也不必都公平周全、坦承缺点和尊重对手；但清醒、理性、礼貌和诚实同样可以属于此人，不为制造性格强加心虚、口吃、脏话或阴暗面。
同职业、熟悉彼此或刻意模仿的人可能说得相近；结合处境判断，不把可辨认当成每人一套方言或口头禅。
用户明确要求同一格式、排比、副歌或正式辩论时保留形式约束，在允许的选材、称呼和语气中呈现人物，不为打散模板改掉任务。
不把最后发言者安排成作者的道德胜者。
分清事实资料、本篇虚构设定与角色的偏见或吹嘘；可以写人物误会与自欺，不暗中改写既定事件以保证一方获胜。

## 2. 选材与信息量：让段落有东西可说

信息量不等于字数、专名或典故计数。这里要保证的是：在本篇长度和受众理解能力内，
主要段落持续带来有区别的经历、关系、能力、处境、选择或对旧事的新理解，使人物越说越具体，而不是同一句道理越说越长。
用户要求密集典故，或所学作品通过连续事迹建立人物时，必须实际选用足够丰富的材料；不能只补一两句点缀便声称解决。

### 先有可用材料，再编排段落

在已有构思笔记中按需要选材，不另建全套档案：

| 选材动作 | 留下能指导写作的内容 |
|---|---|
| 从当场表达行动选经历 | 先看此人此刻愿意提哪件事、避开哪件事、对谁说；再从经历、胜败、关系、手段、处境及自我看法中选材，不先列能力项再配齐证明 |
| 确认材料能怎样被此人讲出 | 同一旧事可以是功劳、耻辱、底气、伤口、笑柄或自我粉饰；先选角色会怎样用，不先写百科解释 |
| 按表现线索分组 | 可按气势积累、人生转折、反差、招式升级或关系变化组织；连续经历应增加侧面或分量，不是同一控诉换证据重说 |
| 区分根据与演绎 | 记清已给材料、可确认的版本与拟虚构表达；史实、演义、改编及角色吹嘘分开，不为增加典故混版本或发明真实战绩 |

材料不足却需扩充时，读取获准材料或核实关键出处；无法核实则缩小、换材或说明不足，不凑数量。
新设虚构人物可在授权范围内设计相互兼容的经历，但须形成此人的行动习惯、处境和声音，不编一串任意功勋充场面。

### 转化成台词，而非报菜名

- **给出与本次主题有关的最小联系。** 按受众熟悉程度取典故的个人贡献、关键动作或影响，不要求把起因、经过、招式和结局逐一复述。熟悉的典故可借一句点出着力处；只有专名而看不出与本次表达的关系时，才补必要联系，不把所有读者都假定成从未接触材料。
- **尽量让材料兼任作用。** 一处具体经历可同时建立身份、暴露性情、形成反差或带动韵律；这是增厚的办法，不是每句必须多义的配额。
- **用讲法组织密集材料。** 偏心、自夸、轻描淡写、反复念叨某件苦活都可能使连续典故成为人物；按本文关系选用，不指定每人一种，不把能力覆盖完整当作材料充分。角色可以真诚坦荡，也不必为显得复杂强添缺点。
- **允许一个主题，避免一份信息反复使用。** 可以始终围绕权力、功业或师徒关系写，但各段应改变经历、关系或看法；同一事件换了真正有意味的视角也可能增加信息，不要求每行换典故。
- **密度与可听懂一起改。** 典故太密造成指代不清、关系断裂或无法断句时，补最少上下文、换顺序、换材料或调整停顿；不一律增加解释，也不一律删到只剩抽象口号。

逐个主要段落问：“除了态度，我具体多知道了什么？这些材料合起来让我多看见此人哪一面？”
如果只能答同一个观点，且现有材料足够丰富，须实际换入或展开有区别的材料，再与压缩方案比较；不能只标记“信息量已检查”。
字数、典故数及每行新信息数仅作诊断线索，不设通用数量门槛。副歌、停顿、蓄势和留白可以不新增事件，前提是它们没有掩盖主体段落的单薄。

## 3. 内容改稿：把讲解改成当场的台词

先看整段让读者听见怎样的人，再检查拖慢它的句子。关键问题是：
**这是此人的开口方式与表现，还是作者借人物之口分析性格、教读者选择？**

人物求情、自辩、解释甚至列功都可能是有效行动；要判断的是作者是否为了预防误解、保证每人都值得认同，而把人物说成无遗漏的正面履历。
先区分两类补充：缺了便无法理解谁做了什么、为何这样反应的，保留必要前提；读者已能从行动感到性情，又补一句能力归纳、品质评价或圆满结论的，比较其是否真有声音、关系或节奏收益。事实核对、演绎说明和出处不因这项判断而取消。

| 需要检查的信号 | 实际改稿动作 |
|---|---|
| 把价值排序写成没有性情的分析，离开角色也能通用 | 用具体经历、口气、夸耀、顾虑或当场作用重写；可以保留有声音的直陈，不必转成对手问答 |
| 罗列自己的事迹、典故或能力 | 看是否形成身份、底气、节奏与积累；可以保留完整人物段落，不要求每项都成为反击论据；仅剩知识装饰时再取舍 |
| 事迹很多，却像作者在逐项补齐优点、反驳潜在批评 | 改变人物选哪件事、怎样讲、对谁讲及在哪里停；不只删概括句，也不以加缺点、减典故或让所有人含蓄代替重组 |
| 一句同时交代前提、解释动机、论证并总结 | 按本段的声音、重音和情绪落点重组，保留理解所需的交代；不只加换行，也不要求句尾都成为质问 |
| 前文已让读者看出意思，后文再宣布寓意或该认同谁 | 比较删留；撤去无新增体验的作者判词，同时保护人物本人的偏见、口头禅和有作用的反复 |
| 各人事迹不同，却都用同样的周全口吻和自证顺序 | 回到听者、当场意图与材料取舍重组存疑段落；不只换自称、方言或形容词，也不要求人人都不理性 |
| 各人都准确概括自己的价值、坦承不足，再用漂亮话收尾 | 判断是否属于人物或明确形式；无依据时撤掉作者替他说出的自我分析，让选择、偏心或关系从当前台词中显出，不机械增加缺点 |
| 先质问、答辩、追问，同一件是非来回说，人物只剩正反方 | 先保留有分量的独立人物段落，移除只为对称补出的接招；用不同经历或认识推进。用户明确选择正式辩论时保留必要论证，但删无推进的复述 |
| 专名很多，却看不出此人具体做过什么、和别人有何关系 | 把关键名词转成能懂的行动或关系，按人物的语气重组；不是在每句后加注释 |
| 为交代典故而逐步复述，挤掉本次陈述的重点 | 先留此人的贡献、关键动作或后果，实际比较压缩后的理解和节奏；只有关键前提缺失才补回，不把自我陈述写成情节复盘 |

对存疑补充实际试删或换一种讲法，放回整段比较：增加了什么人物认识，是否重复已成立的判断，又付出了哪些情绪、韵律和注意力代价。新事实即使有用，也可能打断更有力的停顿或收尾；有损失时重排、重写或保留，不用更短证明更有文学感。仍在现有改稿中处理，不另开审稿轮次或逐句填表。

“因为”“我认为”“我敬你”等只是观察线索，不是禁词；礼貌、完整长句或直陈观点也不自动判差。
说明新前提、承认代价、故意诱导或以客气话挤兑对手，可能正是有效台词。删短后失去理解依据，就恢复或重组。
普通对话不要求句句攻击；对决也允许喘息、铺垫与自夸，不要求每句都是爆点。

看整段、整篇的对照：人物各自讲出了怎样的经历、底气、欲望与局限，两者为何会较劲？
呼应可以跨句、跨段，也可以故意不接招；没有即时反驳不等于缺乏对抗。只有选定问答式攻防时，才核对相应回应是否接续。
重复若形成蓄势、口气、固执或新的反差可以保留；若只是同一是非问题反复论证、又没有声音与人物增益，才合并或删减。
结尾依本篇人物与效果选择，不为双方同样有理或回合对称追加辩解，不用作者判词、刻意认错或和解替读者选胜者。

## 4. 声音改稿：说唱不能只把散文分行

内容可从头接续后，再实际做一轮声音修改。没有伴奏仍执行前三步；有实际音频才执行具体落拍核对。

| 步骤 | 怎样做 | 必须回到正文看什么 |
|---|---|---|
| 找重音与停顿 | 按发音把句子分成可接续的口语节奏；私下可用斜杠试断句，把关键措辞或情绪落点放在容易听清的位置 | 哪些词需要强调，在哪里停；虚词、从句或倒装是否把力度打散 |
| 安排韵脚 | 按实际读音选相邻句、隔句、段内或回环的呼应；允许换韵和有目的的不押韵 | 当前稿哪些词形成什么呼应，不能只写“有节奏”“已考虑押韵” |
| 逐段核读并修卡顿 | 覆盖每个主要说唱段落，连读前后两句的发音与口语顺序；局部卡顿时实际试改，再放回人物段落及全文比较 | 是否一行塞入太多转折、落点被拖长、长短变化没有可辨的组织；不能拿一小段代替全文 |
| 对照伴奏或实际试唱，条件具备时 | 核对真实节拍、重音、换气和时长；只改获准的文本或音频 | 区分文字拟作与实际演唱结果，不编 BPM、试唱记录或已经落拍的结论 |

韵脚依据读音，不依据汉字相似或字面整齐。不要求全文一韵、每句等长或固定字数；
但用户要说唱时，各段应有可辨的声音组织。局部没有尾韵可以用内部韵、重音、复沓或留白承担节奏，
不能一段既无韵脚也无其他组织，仍凭分行宣布声音改稿完成。

避免在句尾反复加同一个语气词冒充唯一韵脚，或为了同韵倒装、造词、塞无意义称呼。
有意的副歌、复沓与口头禅可以保留，前提是它在这篇确有节奏或人物作用。
遇到语义与韵脚冲突，先换韵、调语序或换句式，不改事实、立场、关系或人物动机来迁就押韵。
长句也可以有节奏；短句也可能平。音节长度与韵脚数量只提供线索，不是自动质量分数。

## 5. 回读与记录：检查必须指向当前文字

两轮改稿后连读净稿与相邻人物段落，核对压缩是否丢了必要前提、声音和人物层次，有无把整段表演剪成辩论提纲。
角色台词还要实际做以下比较；单人表达只检查适用部分，不为比较另造人物：

| 怎样检查 | 判断依据与处理 |
|---|---|
| 先只凭正文认识人物 | 不借助构思或性格说明，指出此刻对谁说、想让对方怎样反应，以及支持判断的当前台词。能替正文总结出一种美德，不等于正文已让人感到性情 |
| 换人比较 | 暂时不依靠姓名、自称、职业名和专属典故辨认，比较关键句及主要段落：换给另一个人是否只需替换这些信息？若是，试改说话姿态、选材或顺序；不以删掉全部上下文后能否猜对姓名作硬性测验 |
| 跨段比较结构 | 看不同人物是否都在同一位置让步、举功、解释意义和金句收束。若结构相同，判断是否源于用户指定形式、共同处境或有意模仿；没有这些依据且人物被磨平时，实际重写存疑段落，不只调换词句 |
| 补充的收益与代价 | 指出当前哪些补充只是把已成立的性情或价值说完；存疑处比较删留或换讲法，看是否损失必要前提、具体材料和韵律，或打断有效的情绪、停顿与收尾。不以信息项齐全、少字、缺点数量或含蓄程度验收 |
| 放回关系与任务里复读 | 是否擅自指定裁决者、把所有人都写成向同一人求情，或为了人物姿态漏掉用户要表达的贡献；是否超出其所知、自知程度或当时情绪。变化须兼顾必要事实、信息分量、可理解性及韵律，差异本身不是收益 |

对同质化存疑处实际试出一段不同表达，与原段及相邻人物放在一起比较；可保留原段，但依据须来自当前文字与关系，而非只称“已有人物特点”。
不把此表变成各段必须打印的统一答案；必要记录只保留代表性文字、实际判断和取舍。
有本地记录时，在已有创意笔记中简记以下结果，不另写全篇逐句打分表：

- **人物与台词检查：** 留下上面比较的实际发现与代表性文字，记录改动或保留的依据；不仅总结不同岗位或观点，也不以谁说服谁验收。保留有争议的解释或铺陈时记其实际作用。
- **材料与信息量检查：** 逐个主要段落简记具体材料与新增认识，辨认重复观点、有效回响和必要喘息；核对有没有丰富材料被弃置却把单个争点写满，有没有只堆专名或混淆出处。与声音检查一起回到当前稿，不用数量判通过。
- **声音检查：** 各段当前的句尾呼应或其他节奏安排，实际卡顿与修复；无需逐字标音，也不为凑记录强行改动有效原句。
- **完成范围：** 核过当前哪些段落，哪些只有文字检查，有没有真实音频或未解决问题；不把未做的检查记成已通过。

用户不允许记录时在当前任务内完成；只要正文时不把上述笔记、断句符号、韵脚标注塞进作品。
尚未处理的解释堆叠、与任务要求不符的内容单薄或无组织的声音应先修复，受限制无法修复时明确是内容草稿，不声称说唱稿已完成。
这些记录让修改可回看，不证明听众一定喜欢，也不能由程序匹配字数、关键词或韵母代替编辑判断。

## 合成小例子：不同结构，不同用途

以下为虚构教学片段，不是作家或视频作者原句，也不是要求复用的句式。
给定情境：旧书缺页恰好断在故事的关键处，摊主把缺页也说成旧书的沧桑，仍想上架，馆员主张先补齐。
下面先示意局部问答的改法，再示意完整人物段落；前者不是所有 battle 的模板。

解释型内容稿：“我担心缺页会影响理解，所以我认为应该修复后再提供给读者。”

可试成馆员的两句反击：

> 你把缺页叫沧桑，转身还往架上放，
> 读者追问下一章，你替作者接着讲？

“架上放／接着讲”用相近的 ang 韵收句，“沧桑／下一章”提供段内呼应；
两句都可试作前后两组停顿，例如“你把缺页／叫沧桑，转身还往／架上放”。
这不是实际试唱记录。改法把担忧变成针对上架行为的追问，不能证明馆员已经在所有保存问题上占理；
如果还有另一位角色的段落，可以用自己的经历与声音形成对照，不必立即回答这一问；不把他安排成接受教训的陪衬，也不把馆员的意见宣布为适用于所有保存问题的标准答案。

**完整人物段落也可以形成对抗。** 另设虚构人物：守城者断桥守城、典甲买粮，却挂出降旗；游侠曾单骑闯关、盗敌军令，又拿回赏银救同行。
可把不同材料转成人物自己的夸耀与自我掩饰，而不是让二人争论“谁更有担当”：

> 守城者：桥是我断，城是我守，甲当米粮进了仓；
> 你只见降旗挂城墙，没数过城里几口粮。
>
> 游侠：关我闯，令我盗，赏银拿回救同党；
> 你把姓名留城上，我换姓名过边疆。

“断桥／典甲换粮／降旗”与“闯关／盗令／赏银救人／改名过关”提供不同的行动与处境；
后段借“留名／改名”形成对照，不必逐一回答前段。句中动作与段内停顿共同承担节奏，ang 韵在句尾呼应。
这里的镜像句式用于局部对照，不表示整篇所有人物都应按同一顺序自证；正式成稿仍要看人物、关系与语言是否成立。

**同一目标也可以从不同地方开口。** 虚构老船工与学徒都想留船。西湾有涨水便没顶的木桩；学徒前年已掌过舵，老船工一路责骂，船没有碰桩。
若都写成“我有经验／我有潜力，所以应该留下”，只分出了资格。可试为：

> 老船工：换我也成。西湾那排木桩，涨水就看不见。新来的先别走那边。
>
> 学徒：又说西湾。前年那趟不是我掌的舵？你一路骂，我一路开，可船没碰着一根桩。

前者嘴上退让，仍不放心把船交出去；后者借共同经历争认可，还带着被当学徒的怨气。
这只是当前关系下的两种试法，不规定老人只能含蓄、年轻人只能顶撞，也不强制把人物都写成口是心非。
以上均为虚构教学示意，不是史实、名家原句、实际试唱或信息密度标准。
