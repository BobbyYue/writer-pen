# 版本比较与取舍：用正文决定，不用分差裁决

用于创作、实质改稿后的诊断与版本选择。默认不逐项打分；只有用户明确要求评分时，
才使用文末的十档尺度。评分是诊断记录，不是修改裁判，也不是客观文学测量或读者测试。

## 先明确目标、底稿与判断性质

在试写前明确此次要改善什么，以及不能改变什么。用户要求从原始材料重写时，
重新读取原文，不沿用上一稿的结构、分数或删减决定；仍明确有效的局部保留要求单独记明。
用户解除历史改法约束后按当前目标重判，有效写法不因来自旧稿被排除，但须放回本轮上下文检验。
不能把“按用户要求沿用”说成新的比较胜出，也不能在删改后临时改变目标为它辩护。

区分三类判断，不能用同一种通过标准处理：

| 判断性质 | 怎样处理 |
|---|---|
| 用户明确要求 | 遵守指定保留内容、字数及修改范围，不自行增加限制 |
| 可修复的作品问题 | 指出具体文字造成的误读、无依据行动、时空冲突、场景不足等，并尝试修复；按作品自身规则判断，不把荒诞、留白或不可靠叙述一律当错 |
| 有依据的审美取舍 | 速度与停留、明晰与含蓄、声音与紧凑等可能各有得失。按本篇目标和全篇效果选择，不要求每个维度都提升，也不宣称存在通用最佳版本 |

写前人物分析是有依据的初始理解，不是人物必须服从的答案。写后允许发现更复杂的人，
但发展须有正文支撑并另存版本；不能覆盖封存记录来假装前后从未有分歧。

## 先读作品，再比较改法

按 [净稿通读](read-through.md) 连贯阅读正文，先记住整体留下的人物、经历、声音和未解之处，
再借助下方诊断索引定位具体原因，不边读边给每一格凑分数。
同一模型暂时放开提纲后的通读仍是自查，不是独立盲读或真实读者反馈。

比较基准与认真发展的候选：小改读必要上下文；开头读完整进入单元并接回后文；
关键情节读必要前提、冲突过程及后续反应。删除后仍然通顺，只证明衔接成立，
不能证明人物的选择、关系张力或情绪经历没有损失。批注中的意图也不能代替正文效果。
候选明显牺牲原有长处时，先尝试更合适的改法；不能用草率短版证明原文不可改善。

## 根据实际得失作取舍

- **采用**：具体改善服务当前目标，相关损失可以被实际收益合理解释，且不违背明确约束。
  同分也可以采用；无需为证明改善而升分，更不必在所有维度上胜出。
- **保留**：原处理本身成立，候选收益不足、主要只是偏好差异，或比较后仍无法判断更好。
  保留是本轮选择，不等于原文已无改进空间。
- **再试**：原文或候选仍有实质问题，或有值得保住的作用却被改法损伤。可修复、压缩、
  移位或重构；两版都有问题时不能把较不差的一版称为已解决，也不机械退回有硬伤的原文。
- **待比较**：尚未读完必要上下文、没有实际形成候选或缺少关键材料。说明范围与不确定性，
  不把尚未比较写成通过。能在当前任务中继续完成的比较应继续做，不以此回避选择。

发现相关项退步时重新比较，但损失不是自动否决，写出代价也不是自动许可。
采用有损失的版本前，指出原版失去的具体作用、候选获得的具体收益，以及该收益为什么
对本篇更重要。“更集中”“更简洁”只是待验证的理由，要说明减少了什么干扰、突出什么经历。
更高的分数不能抵消未经解释的人物削弱；同样，有依据的节奏选择也不因少了一层信息就必然错误。
用户明确选择某种代价时遵从其有效要求，交代必要影响，不冒充全面改善。

选择后回修前提、指代、时序和后果，再读受影响的联系。实质重写还须重新连读净稿。
当前目标已实现、没有尚未处理的关键问题，也没有有根据的新改法时停止。
仍有问题但因缺少材料或权限不能处理时如实交代，不以“已经打分/通读”宣布解决。

## 开头替换：原开头也是候选

自主改换开头前，实际对照新旧开头；各读到相对完整的进入单元，而非机械截相同字数。
分别指出继续阅读的理由、人物声音与进入方式、理解成本，以及后文能否兑现开头的期待。

- 替换须有足以支持本次目标的整体改善，并说明重要代价；不以某一项加分或所有项不降分为条件。
  日常、慢速、陌生化的开头可以有效，吸引力也不只来自悬念。
- 原开头有效而候选收益不明、只赢在偏好或尚未比较时，保留原开头，可另列备选。
  若原开头确有问题，则修复或另试，不能用“存疑就保留”放任已知问题。
- 候选须认真保留原有长处并解决目标问题。弱候选落选不能证明原开头已经最好。
- 更强的悬念若正文不兑现，或依赖越过授权边界的事件，不构成有效改善。
- 用户明确指定恢复或更换时照办并处理相关影响，不把用户选择伪称为评分胜出。

## 标题替换：在同一正文上比较

按 [文学标题](titles.md) 比较原题与候选的命名依据、读前期待、读后意味与声音。
题名须与当前全文相连，不能用旧稿中的意象或尚未写入的情节为新题辩护。
标题较短、较华丽、较含蓄或更像某位作家，不足以证明改进；原题有效而收益不清可保留。
只改标题不顺手改正文；全文任务将题名并入送审候选，改题后不能宣称旧版本审读覆盖了新题。
复用本页的采用、保留、再试、待比较及简短记录，不新增文学总分或统一题名字数标准。

## 记录保持简短，依据放在分数之前

对影响较大或存在争议的改动，留下必要的比较记录；不要求每句话填表：

> 范围/版本 → 本次目标 → 原文与候选依据 → 收益/损失 → 采用/保留/再试/待比较 → 不确定性

引用必要文字或明确正文位置，说明选择理由；没有实质不确定性时无需硬凑一项。
判断与比较应在采用前形成。事后补评须标为事后，不伪造此前已经比较、试过又撤回的历史。
用户要求评分时，在依据之后附相关分项档位，不另造总分或用档位替换理由。
局部修改只记录受影响范围；未读的部分不声称已检查。通常交付作品与必要说明，
用户要求改稿实录时再展示完整记录，不默认输出整张诊断表。
实质创作与改稿的版本绑定、问题处理及交付核对见 [执行与核对](execution.md)；常见判断的操作见 [具体方法](operations.md)。

## 诊断索引，不是逐项评分表

以下A—E编号沿用既有检查项，用于定位问题和连接通读记录。
完整创作与重写需覆盖适用的阅读问题，但不必每项形成独立记录；相关项目可以共用正文依据。
局部任务只看受影响项目。执行了检查，不意味着文学效果已被证实。

| 编号 | 检查项 | 判断依据与修改方向 |
|---|---|---|
| A1 | 行为与台词 | 此人此刻面对这个对象为何如此行动，有具体处境支撑，而非仅符合身份标签；突兀则改反应、撤回或补必要前提 |
| A2 | 读者所知 | 意义所需的信息能获得；缺失则补回或前移，留白不等于遗漏 |
| A3 | 因果与时空 | 时间、对象、回应可恢复；矛盾则回修前后，不把倒叙判错 |
| A4 | 情绪与选择 | 变化有过程或可感依据；跳跃则发展经历或缩小转变 |
| A5 | 细节与虚构 | 分别判断是否符合具体人物及是否值得写；泛化职业道具、为巧合服务的设计可撤回，环境气氛不强求人物功能 |
| A6 | 整体声音 | 口吻与叙述关系成立；失调则重配语言，不一律改成朴素克制 |
| B1 | 换段理由 | 边界对应关注、场景或节奏变化；无效停顿试合并 |
| B2 | 段间承接 | 动作与心理推进完整；断裂试重组，保留有意断裂的效果 |
| B3 | 强调分配 | 重要处获得合适分量；普通过渡抢重音时调整边界或落点 |
| B4 | 长短与速度 | 长短段服务当前声音与速度；过碎或过满时试读拆合 |
| B5 | 归属与版面 | 对话、动作主体可辨，净稿不被批注容器切碎；据此修排版与分段 |
| C1 | 人物及依据 | 先由正文概括人物，再对照封存的五层分析及反例；无支撑则修正文，有依据的发展另存版本，不倒改基准 |
| C2 | 细节与共鸣 | 具体处境承载感受；泛化或装饰时换细节，不靠加惨事制造共鸣 |
| C3 | 开头的继续阅读欲望 | 有可指认的兴趣、声音或气氛，后文能兑现；替换须实际比较原开头 |
| C4 | 结尾的余味 | 留下适合全文的动作、声音或问题；弱时重选落点，不强造金句 |
| D1 | 细节的具体收益 | 删后损失能够指认；只说更丰富时回到保留版与删除版 |
| D2 | 与已有表达的区别 | 有新层次、反差或有效回响；同义重复时删、并或重排 |
| D3 | 收益与阅读代价 | 增益值得当前位置的停留；拖慢或转移重心时压缩、移位或删 |
| D4 | 取舍后的整体效果 | 比较选择、过程及后果的得失，不只看删后连贯；原处理成立且候选收益不明可保留，两版都有问题则再试 |
| E1 | 叙述位置 | 时点、知情范围与感受一致；作者解释压过人物时调整距离 |
| E2 | 细节之间的联系 | 注意、记忆、行动或气氛能相互承接；清单化时重组，不强造因果 |
| E3 | 场景展开的充分性 | 重要经历不只剩结论；过薄时展开必要体验，避免补流水账 |
| E4 | 个性与复杂性保留 | 修改没有无故磨掉有作用的声音、矛盾、留白；有损失时比较具体得失后恢复、另试或有依据地接受代价 |

D1—D4用于存疑细节或相应段落，不要求逐句制作双稿。
通读是否完成、来源是否核对、权限是否满足属于执行状态，不是审美档位；不能用高分掩盖未执行。

## 用户明确要求时，使用十档评分

评分仅作当前任务、当前阅读范围内的编辑诊断，不评作者文学水平或客观质量百分比。
先形成文字判断，再为用户要求的相关项记录1—10档整数；不默认扩展为所有项目的评分。
不用小数、平均分、加权总分、统一及格线或“至少提升几分才改”的门槛。

| 档位 | 含义 | 诊断提示，不是自动指令 |
|---|---|---|
| 1 | 该项的关键关系或效果缺失，无法据正文成立 | 查找缺失的基础 |
| 2 | 已有相关线索，但关键矛盾或断裂使效果不能成立 | 找核心断裂，不靠润色掩盖 |
| 3 | 能辨认表达意图，但明显误读或失真阻碍阅读 | 指出障碍文字与可能重构方向 |
| 4 | 局部有效，但一处显著损失仍牵制该项效果 | 同时看局部作用及关联损失 |
| 5 | 基本成立，仍有明显薄弱或未充分展开之处 | 找值得发展的部分 |
| 6 | 连贯可信，基本效果已实现，表现层次仍有限 | 考虑有依据的深化，不机械加情节 |
| 7 | 有效且有具体支撑，仍有可指认的拖累或不足 | 识别拖累与已有长处 |
| 8 | 作用充分，与人物和全篇配合良好，主要短板已解决 | 不为变化而变化 |
| 9 | 在充分有效之外有鲜明、贴合此人物或作品的表现，难以被泛化写法替代 | 注意独特作用是否被修平 |
| 10 | 该项在当前作品中表现突出，比较后未找到有依据的进一步改善 | 不代表完美或普遍最高标准 |

不适用写N/A，未读到或证据不足写“未评”，不计低分。字数、段数、修辞数量、
删改比例和虚构多少不能直接决定档位；低分必须对应具体阅读问题，而非个人风格偏好。
无法说明相邻档的区别时不要硬拉分差，可同档并注明不确定性。十档更细不等于测量更准。
同档仍可有实际改善，高分也不能证明人物更可信；采用的版本若有退步如实记录，不能抬分制造全面胜出。

旧版五档记录保留原尺度，不乘二冒充重新评估。确需跨版本比较时重新读两版，
用同一十档尺度重评并标明范围；不把旧五档与新十档直接相减，也不把事后评分伪称为先前决策依据。

## 区分日常自查与体系评估

以上流程是每次写作的编辑方法，不是文学质量认证。对skill本身的长期评估另行安排：
使用合成或已获授权的材料，保留任务目标与评价分歧，必要时请真实读者或编辑比较版本。
不同模型复核可补充视角，但不能冒充人类读者测试；程序核对只能证明对应的结构或执行条件。
不在每次写作中强制建立数据集、组织多人打分，也不把用户私稿自动收入测试或案例库。
