# 作家那支笔 | Writer Pen

用于中文文学创作、改稿与创意文案的 Skill。从人物和处境出发，把素材写成作品，把修改落到具体文字。

支持短篇小说、文学散文、人物与场景片段的构思、起草、续写、实质改稿、拟题与写作练习。完整作品默认交付可离线打开的 HTML，用户指定格式优先。

创意文案有独立的写作路径，支持主题创意、叙事文案、角色对话、品牌或活动创意表达，以及说唱、口播和视频脚本。按实际用途选方法；纯文字任务不会自动变成视频脚本。

### 经还在西边

取经未成，队里要减一人。

#### 唐僧

揭一纸佛帖，收一声师父，<br>
贫僧把五行山下的猴王，<br>
带上西行路。

女王拿一国江山，<br>
换贫僧留下成亲。<br>
徒弟去灵山，贫僧做国君。<br>
喜筵上催她盖的，<br>
仍是西行的印。

长安法坛，菩萨说真经能度苦，<br>
贫僧下坛，请命西行。<br>
那时还不识悟空，<br>
不识八戒、悟净，<br>
十万八千里，已在佛前应承。

一炷香，一身凡骨，<br>
此去吉凶，便都押在这条路。<br>
经不回东土，<br>
贫僧不回长安。

#### 孙悟空

砍头，剖腹，滚油锅，<br>
车迟国三场，老孙全接过。

狮驼国，群妖架火，<br>
老孙搬龙王，先护锅底，<br>
保住这一笼和尚。<br>
大鹏的外甥坐灵山，<br>
俺去请他挪莲台，亲自来收场。

白虎岭，三棒打出白骨，<br>
一纸贬书，赶老孙回山。<br>
身回水帘洞，心逐取经僧。

宝象国一声告急，老孙又下了山。<br>
黄袍怪把师父变作虎，<br>
老孙一声咒，一口水，<br>
虎笼里，喷回个唐三藏。<br>
他连声道谢，老孙把棒一扛：<br>
“留着，到灵山再谢。”

#### 猪八戒

八百里荆棘，缝住西行道，<br>
老猪长身，长钯，<br>
一日一夜，刺往两边倒。

花果山，头磕了，大哥不动。<br>
俺替黄袍怪添两句骂，<br>
往他耳边一送。<br>
束虎裙，抄铁棒，纵身下山；<br>
来时俺求他，去时他催俺。

真假猴王，闹上天庭，闹下阴曹，<br>
水帘后那两包行李，<br>
还得有人去挑。<br>
俺认不准猴哥，却认得洞门。<br>
进洞抡钯，出洞背囊，<br>
关文、袈裟，这一伙人的家当，<br>
老猪给扛回来了。

#### 沙僧

八百里流沙，鹅毛沉底。<br>
颈上九颗骷髅，<br>
解下来结作法船。<br>
俺这双夺过人命的手，<br>
这回，托着师父过河。

真假猴王那一场，<br>
师父挨了棒，关文遭了抢，<br>
这笔账，全记在大哥头上。

俺闯水帘，奔南海，扯他回山，<br>
让那张借来的脸，<br>
当面见一见正主。

狮驼国，满城传：<br>
师父已入妖腹。<br>
大哥引俺到柜前，<br>
哭声从铁缝里漏出。

俺抡杖，砸锁，揭柜盖，<br>
从一城死讯里，<br>
扶出个活生生的师父。

#### 白龙马

鹰愁涧，龙身换作马身，<br>
西海的浪，换了一路风尘。<br>
驮的是师父，挣的是金身。

朱紫国，国王卧病，师父作保。<br>
三位师兄捧着盏，围到我马槽。<br>
几滴龙尿，和进乌金丹，<br>
三年沉疴，一朝散；<br>
国王下病榻，师父上马鞍。

宝象国，师父困虎笼，<br>
师兄无音信，我先挣断缰。<br>
变宫娥，舞宝刀，直取黄袍。<br>
负伤回槽。

二师兄要散伙，我咬住他的袍：<br>
“大哥还请得回，<br>
师父还救得了。”

## 文学写作案例：《周一见》

**《周一见》** · 一篇1000字以内的短篇小说。原始输入与整理后的重写提示词分别保留。

<details>
<summary><strong>展开原始提示词与作品全文</strong></summary>

### 原始提示词

<!-- example:prompt:start -->
```text
使用以下素材用writer-pen 写一篇短篇小说，1000字以内
“主包早年在某新能源实习的时候遭遇过的直面询问包括但不限于：“你是处男嘛”“你介意我把你睡了吗”“你还蛮好亲的”的纯爱经历一度以为要结婚了直到主包在被锐评为你还蛮好亲的的第二天看到公司的那位女生牵手和另一位男同事在烧烤摊从我面前走过”
```
<!-- example:prompt:end -->

<!-- example:story:start -->
### 周一见

她问“你是处男嘛”的时候，我来这家新能源公司还不到两个星期。我说：“实习生还要查这个？”她笑了半天。我回到宿舍，还在想自己刚才是不是显得挺会说话。

后来她下班总来问我走不走。有次我还在改表，她把包放回工位，说那等你一会儿。我越着急越改不对，她看了一阵，去楼下买了两个饭团，分给我一个。

第二个月，快到六点，我就往她那边看。她临时开会，我在楼下等了四十分钟，见了面却说自己刚下来。有一次我跟同事先去吃了饭，收到她的消息：你怎么不等我？我赶紧回，明天肯定等。

有天吃完晚饭，她说住得不远，要走回去。我说送你，她说好。快到楼下时，她忽然问：“你介意我把你睡了吗？”我说不介意，答得很快。她笑我像在回复工作消息。我还想说点什么，她已经刷卡进了门。

实习快结束时，室友问我哪天回去，好一起买票。我说月底。那天晚饭，我跟她提起这事，她问我怎么不留下。我说还不知道能不能转正，她说，那你问问呗。

第二天我去找主管。他说有名额，还要面试，让我准备一下，下周谈。晚上我把这事告诉她，她说加油。饭后我照旧送她回去，一个人往宿舍走时，把沿路几处租房广告拍了下来。

那周五晚上，送她到楼下，她没有急着进门，转过身亲了我，说：“你还蛮好亲的。”回去的路上，手机响了，是室友又在问车票。我回他，先别买我的，我想留在这边。

周六下午，我问她晚上要不要一起吃烧烤。等到七点还没回，我饿了，便到公司附近的摊子坐下，点了些烤串。

烤串刚端上来，我看见她牵着另一个男同事走过来。她停在桌边，问我一个人啊。我说嗯。

男同事问，要不要一起吃点？

我看着她，她也看着我。“不用了，我快吃完了。”我拿起一串咬下去，烫得没法咽。

她说：“那我们先走了，周一见。”

“周一见。”我说。
<!-- example:story:end -->

### 这版主要改了什么

没有照搬“一度以为要结婚”的概括，而是通过等下班、问转正、拍租房广告、推迟买票，让期待进入人物的实际生活。修正邀约与吃饭的行动顺序，交代重要换场，再把同一次交流中的碎段连起来。结尾保留必要停顿，不另加情绪总结。

案例已实际完成隔离的专业审稿、读者回读和页面检查；但专业审稿记录的格式校验未通过，尚未完成整套终稿验收。本例保留为重写稿，不作为“端到端成功”的证明。

## 安装与使用

首次安装到 Codex 的个人 Skill 目录：

```bash
git clone https://github.com/BobbyYue/writer-pen.git ~/.codex/skills/writer-pen
```

已有同名目录时先保留本地修改，不直接覆盖。在支持 Skill 的会话中可以这样请求：

```text
用 writer-pen 把下面的素材写成一篇1000字以内的短篇小说。
用 writer-pen 重写这篇小说，重点看关系的发展是否可信、场景能否接得上。
用 writer-pen 检查这几个段落：哪里停顿有作用，哪里只是把一次交流拆散了？
```

核心脚本使用 Python 标准库。独立审读需要宿主提供实际调用能力；HTML 页面检查另需 Node.js、Playwright 和可用浏览器。只加载提示词，不等于完整流程已经运行。操作见 [统一写作入口](references/workflow.md)。

## 文学写作流程

1. 读材料，区分必须遵守的要求、暂时解释和可调整的创作选择。
2. 写前封存人物理解，拟工作标题；素材中的概括不强迫正文逐句兑现。
3. 起草或改稿，再从头连读净稿；对存疑处实际试改，比较得失。
4. 专业审稿与独立读者分别阅读。读者只收作品与中性问题，不收作者意图或其他审稿意见。
5. 核对当前稿、审读记录和实际页面，再交付；需要改稿时累计最多三轮，不换目录重置轮次。

段长、短句比例和重复次数只是检查线索，不是文学质量评分。它不把作品统一改成克制口吻，不强造反转、金句或唯一主题。

## 创意文案流程

先确定用途、素材和可虚构的范围，再选择切入角度，组织有具体内容的段落，最后分别检查表达与相应形式。例如，角色对话要让人物的经历和口气有区别；说唱还要实际修改韵脚、重音与停顿。没有伴奏或试唱记录时，只说明完成了文字检查。

可以这样请求：

```text
用 writer-pen 的创意文案场景，把下面的素材写成两位虚构人物的对话。
各自的经历和在意的事情要能从话里看出来，不替他们判输赢。
只给纯文字，不加分镜；保留素材里已经确定的事实。
```

具体方法见 [创意文案](references/creative-copywriting.md) 和 [台词与说唱改稿](references/dialogue-and-rap.md)。小说、散文继续使用文学流程，两类稿件分别检查。

## 目录与验证

```text
SKILL.md             技能入口
agents/              宿主展示信息
references/          按问题读取的写作与检查方法
scripts/             版本、封存、审读采集与交付程序
config/              版本信息及执行配置
assets/              自包含文学页面模板
tests/               程序回归测试
evals/               专项行为评估材料
examples/            获准公开的提示词、文章及案例说明
docs/                已知限制
tools/               仅发布时运行的仓库检查
```

在仓库根目录运行：

```bash
python3 -m unittest discover -s tests -p 'test_*.py' -q
node tests/test_writing_host.js
python3 tools/check_repository.py
```

CI 在 Python 3.9 和 3.12 上执行。程序测试检查版本、引文、阶段、约束与异常分支；真实作品的阅读效果仍需作品审读和读者反馈，不能用测试数量替代。详见 [维护测试](references/testing.md)。当前为预发布版，[已知限制](docs/known-limitations.md)单独保留。

私稿、人物分析、原始审稿返回、账号信息和本机任务状态不属于公开包。新增案例须另获授权，不把用户作品自动收进回归测试集。
